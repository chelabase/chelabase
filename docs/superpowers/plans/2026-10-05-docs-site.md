**Schema rules (from the parser, `crates/chelabase-query/src/query.rs:397-555`):**
- `TableName`: string, pattern `^[^.]+(\.[^.]+)?$`.
- `database`: string, `minLength 1`, `maxLength 63` (bytes on the server; P3), top level only.
- Batch: `op: "batch"`, `ops` array `maxItems 50` (no minimum), items oneOf the five batch members; only `op`, `ops`, `v`, `database` allowed; no nesting.
- Select: `from` (TableName, required), `select` (array of SelectItem, `minItems 1`), `where` (Filter or null), `orderBy` (array of OrderBy), `limit`/`offset` (integer, `minimum 0`, or null).
- SelectItem: string, or `{col: string, as: string (minLength 1, maxLength 63)}` both required, closed.
- OrderBy: `{col: string (required), dir?: "asc"|"desc", nulls?: "first"|"last"}`, closed.
- Insert: `into` (TableName), `values` (array `minItems 1` of objects with `minProperties 1`), `returning?`.
- Update: `table`, `set` (object `minProperties 1`), `where?`, `all?` (boolean), `returning?`; plus `anyOf [{required:[where]}, {properties:{all:{enum:[true]}}, required:[all]}]` (inner objects must not set `additionalProperties`).
- Delete: `from`, `where?`, `all?`, `returning?`, same anyOf.
- Call: `fn` (TableName), `args?` (object, values any JSON).
- Returning: `enum ["*"]` or array of strings `minItems 1`.
- Filter: `oneOf [ {and: [Filter] minItems 1}, {or: [Filter] minItems 1}, {not: Filter}, Cond ]`, each closed; Cond: `col` string required; `eq neq lt lte gt gte`: type `[string, number, boolean, array, object]`; `in`: array; `is`: type `[null, boolean]`; `like`/`ilike`: string; `minProperties 2`, `maxProperties 2`.
- Every object closed (`additionalProperties: false`) except where noted.
