# API Gateway Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the TCP stub in `apps/gateway` with a Pingora-based HTTP front door. Routes are declared once in a shared crate, and the gateway verifies Zitadel JWTs and forwards a gateway-signed internal identity token to the orchestrator.

**Architecture:** A new dependency-free crate `cheladb-routes` declares every public endpoint (method, path, service, typed policy). The orchestrator builds its axum router from those declarations, and a drift test keeps the two in sync. `cheladb-auth` gains an `internal` module that signs and verifies EdDSA tokens.

The gateway has a pure pipeline (request id → host scope → route → CORS → auth → identity minting) with no Pingora types. A thin `proxy.rs` adapts it to Pingora's `ProxyHttp`. The orchestrator trusts only the internal token.

**Tech Stack:** Rust 2021, Pingora 0.9 (`pingora-core`, `pingora-proxy`, `pingora-http`, `pingora-error`), axum 0.8 (orchestrator and test mocks), `jsonwebtoken` 9 (RS256 for Zitadel, EdDSA for internal tokens), `ed25519-dalek` 2, `arc-swap` 1, `just`.

**Spec:** `docs/superpowers/specs/2026-09-27-gateway-design.md`

## Global Constraints

- Pingora crates are pinned at `0.9` with default features. No TLS feature is enabled.
- Building needs `cmake` on `PATH`, because Pingora always compiles zlib-ng. If `cmake --version` fails, stop and ask the user to run `sudo apt-get install -y cmake`.
- In `apps/gateway/src`, only `proxy.rs` and `main.rs` may reference `pingora`.
- `cheladb-routes` has **no dependencies**.
- Internal token: EdDSA JWT in header `x-cheladb-identity`, `iss = "cheladb-gateway"`, `aud` = target service name (`"orchestrator"`), TTL 60 s, verify leeway 5 s.
- Env and defaults:
  - `CHELADB_GATEWAY_ADDR=127.0.0.1:8000`
  - `CHELADB_ORCHESTRATOR_URL=http://127.0.0.1:8081`
  - `CHELADB_PLATFORM_HOSTS=` (empty means every host is Platform)
  - `CHELADB_STUDIO_ORIGINS=http://localhost:3000`
  - `CHELADB_INTERNAL_SIGNING_KEY` (path, gateway)
  - `CHELADB_INTERNAL_VERIFY_KEY` (path, services)
- Error bodies are JSON `{"error":"..."}`.
- The gateway never forwards `Authorization` or a client-supplied `x-cheladb-identity` upstream.
- Commits: git has no global identity here. Commit with `git commit ...` and end every message with:
  ```
  Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>
  Claude-Session: https://claude.ai/code/session_01KESSEqEbiuKm7pMwCPe2Wg
  ```

## Review Focus

1. **A `401`/`503` from the gateway on a Studio-CORS endpoint** must carry `Access-Control-Allow-Origin`. Otherwise the browser hides the real error behind a CORS failure. (Task 6)
2. **A forged `x-cheladb-identity` sent to a *public* route** (e.g. `/health`) must never reach the upstream, not just on authenticated routes. (Task 7)
3. **Host headers with a port, uppercase letters, an IPv6 literal, or no Host at all** must resolve correctly when `CHELADB_PLATFORM_HOSTS` is set, and a missing Host must be rejected. (Task 5)
4. **Only one of the two key files present** (e.g. someone deleted the private key) must make bootstrap fail loudly. Silently regenerating would break a running orchestrator. (Task 4)
5. **Path edge cases:** a trailing slash (`/v1/databases/`) is `404`, and a query string (`?verbose=1`) is ignored for matching but forwarded upstream unchanged. (Tasks 1 and 7)

```rust
//! Public HTTP endpoints of Cheladb services.
//!
//! One declaration per endpoint, shared by the gateway (routing + policy) and
//! the owning service (axum route paths), so the two cannot drift. Path
//! templates use axum's `{param}` syntax.

#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash)]
pub enum Method {
    Get,
    Post,
    Put,
    Patch,
    Delete,
}

impl Method {
    pub const fn as_str(self) -> &'static str {
        match self {
            Method::Get => "GET",
            Method::Post => "POST",
            Method::Put => "PUT",
            Method::Patch => "PATCH",
            Method::Delete => "DELETE",
        }
    }

    /// Parse an HTTP method token. Tokens no endpoint can declare (`OPTIONS`,
    /// `HEAD`, lowercase variants, …) return `None` and never match.
    pub fn parse(token: &str) -> Option<Method> {
        match token {
            "GET" => Some(Method::Get),
            "POST" => Some(Method::Post),
            "PUT" => Some(Method::Put),
            "PATCH" => Some(Method::Patch),
            "DELETE" => Some(Method::Delete),
            _ => None,
        }
    }
}
```

```rust
fn match_in(endpoints: &'static [Endpoint], scope: Scope, method: &str, path: &str) -> Match {
    let method = Method::parse(method);
    let mut best: Option<(&'static Endpoint, Vec<bool>)> = None;
    let mut allowed = Vec::new();

    for ep in endpoints.iter().filter(|ep| ep.scope == scope) {
        let Some(specificity) = path_specificity(ep.path, path) else {
            continue;
        };
        if Some(ep.method) == method {
            let better = best
                .as_ref()
                .map_or(true, |(_, current)| specificity > *current);
            if better {
                best = Some((ep, specificity));
            }
        } else if !allowed.contains(&ep.method) {
            allowed.push(ep.method);
        }
    }

    match best {
        Some((ep, _)) => Match::Found(ep),
        None if !allowed.is_empty() => Match::MethodNotAllowed(allowed),
        None => Match::NotFound,
    }
}

/// If `template` matches `path`, return one flag per segment (`true` = literal
/// segment), so literal matches compare greater than param matches.
fn path_specificity(template: &str, path: &str) -> Option<Vec<bool>> {
    let template = template.strip_prefix('/')?;
    let path = path.strip_prefix('/')?;
    let template_segments: Vec<&str> = template.split('/').collect();
    let path_segments: Vec<&str> = path.split('/').collect();
    if template_segments.len() != path_segments.len() {
        return None;
    }
    template_segments
        .iter()
        .zip(&path_segments)
        .map(|(t, p)| {
            if t.starts_with('{') && t.ends_with('}') {
                (!p.is_empty()).then_some(false)
            } else {
                (t == p).then_some(true)
            }
        })
        .collect()
}
```

```rust
//! Gateway-minted internal identity tokens.
//!
//! The gateway verifies an external credential (a Zitadel JWT today), then
//! signs a short-lived EdDSA JWT describing the caller for exactly one
//! upstream service (`aud`). Services verify it with the gateway's public key
//! and never talk to the identity provider. Asymmetric keys mean a service can
//! verify tokens but cannot mint them.

use crate::AuthError;
use jsonwebtoken::{decode, encode, Algorithm, DecodingKey, EncodingKey, Header, Validation};
use serde::{Deserialize, Serialize};
use std::path::Path;
use std::time::{SystemTime, UNIX_EPOCH};

pub const INTERNAL_ISSUER: &str = "cheladb-gateway";
/// Request header carrying the internal token from the gateway to a service.
pub const IDENTITY_HEADER: &str = "x-cheladb-identity";
pub const INTERNAL_TOKEN_TTL_SECS: u64 = 60;
const LEEWAY_SECS: u64 = 5;

/// How the gateway authenticated the caller.
#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "snake_case")]
pub enum AuthMethod {
    PlatformJwt,
}

/// The caller, as established by the gateway.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Identity {
    pub sub: String,
    pub org_id: String,
    pub auth: AuthMethod,
    pub request_id: String,
}

#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
pub struct InternalClaims {
    pub iss: String,
    pub aud: String,
    pub iat: u64,
    pub exp: u64,
    pub sub: String,
    pub org_id: String,
    pub auth: AuthMethod,
    /// Gateway request id, for following one request across services.
    pub rid: String,
}

pub struct InternalSigner {
    key: EncodingKey,
}

impl InternalSigner {
    /// From a PKCS#8 PEM Ed25519 private key.
    pub fn from_pem(pem: &[u8]) -> Result<Self, AuthError> {
        EncodingKey::from_ed_pem(pem)
            .map(|key| Self { key })
            .map_err(|e| AuthError::Config(format!("internal signing key: {e}")))
    }

    pub fn from_pem_file(path: &Path) -> Result<Self, AuthError> {
        Self::from_pem(&read_key(path)?)
    }

    /// From the file named by `CHELADB_INTERNAL_SIGNING_KEY`.
    pub fn from_env() -> Result<Self, AuthError> {
        Self::from_pem_file(Path::new(&env_path("CHELADB_INTERNAL_SIGNING_KEY")?))
    }

    pub fn sign(&self, audience: &str, identity: &Identity) -> Result<String, AuthError> {
        self.sign_at(audience, identity, now_secs())
    }

    /// Sign with an explicit issue time (seconds since the Unix epoch).
    pub fn sign_at(
        &self,
        audience: &str,
        identity: &Identity,
        issued_at: u64,
    ) -> Result<String, AuthError> {
        let claims = InternalClaims {
            iss: INTERNAL_ISSUER.to_string(),
            aud: audience.to_string(),
            iat: issued_at,
            exp: issued_at + INTERNAL_TOKEN_TTL_SECS,
            sub: identity.sub.clone(),
            org_id: identity.org_id.clone(),
            auth: identity.auth,
            rid: identity.request_id.clone(),
        };
        encode(&Header::new(Algorithm::EdDSA), &claims, &self.key)
            .map_err(|e| AuthError::Config(format!("sign internal token: {e}")))
    }
}

pub struct InternalVerifier {
    key: DecodingKey,
}

impl InternalVerifier {
    /// From an SPKI PEM Ed25519 public key.
    pub fn from_pem(pem: &[u8]) -> Result<Self, AuthError> {
        DecodingKey::from_ed_pem(pem)
            .map(|key| Self { key })
            .map_err(|e| AuthError::Config(format!("internal verify key: {e}")))
    }

    pub fn from_pem_file(path: &Path) -> Result<Self, AuthError> {
        Self::from_pem(&read_key(path)?)
    }

    /// From the file named by `CHELADB_INTERNAL_VERIFY_KEY`.
    pub fn from_env() -> Result<Self, AuthError> {
        Self::from_pem_file(Path::new(&env_path("CHELADB_INTERNAL_VERIFY_KEY")?))
    }

    /// Verify signature, issuer, expiry, and that the token was minted for `audience`.
    pub fn verify(&self, token: &str, audience: &str) -> Result<InternalClaims, AuthError> {
        let token = token.trim();
        if token.is_empty() {
            return Err(AuthError::Unauthorized);
        }
        let mut validation = Validation::new(Algorithm::EdDSA);
        validation.set_issuer(&[INTERNAL_ISSUER]);
        validation.set_audience(&[audience]);
        validation.set_required_spec_claims(&["exp", "iss", "aud"]);
        validation.leeway = LEEWAY_SECS;
        decode::<InternalClaims>(token, &self.key, &validation)
            .map(|data| data.claims)
            .map_err(|e| AuthError::InvalidToken(e.to_string()))
    }
}

/// A fresh Ed25519 keypair as (PKCS#8 private PEM, SPKI public PEM).
#[cfg(feature = "keygen")]
pub fn generate_keypair_pem() -> (String, String) {
    use ed25519_dalek::pkcs8::spki::der::pem::LineEnding;
    use ed25519_dalek::pkcs8::{EncodePrivateKey, EncodePublicKey};

    let signing = ed25519_dalek::SigningKey::generate(&mut rand::rngs::OsRng);
    let private = signing
        .to_pkcs8_pem(LineEnding::LF)
        .expect("encode ed25519 private key")
        .to_string();
    let public = signing
        .verifying_key()
        .to_public_key_pem(LineEnding::LF)
        .expect("encode ed25519 public key");
    (private, public)
}

fn env_path(var: &str) -> Result<String, AuthError> {
    std::env::var(var).map_err(|_| {
        AuthError::Config(format!(
            "{var} is not set; run `just zitadel-bootstrap` and load .cheladb/zitadel/demo.env"
        ))
    })
}

fn read_key(path: &Path) -> Result<Vec<u8>, AuthError> {
    std::fs::read(path).map_err(|e| AuthError::Config(format!("read {}: {e}", path.display())))
}

fn now_secs() -> u64 {
    SystemTime::now()
        .duration_since(UNIX_EPOCH)
        .map(|d| d.as_secs())
        .unwrap_or(0)
}
```

```rust
pub fn ensure(dir: &Path) -> Result<InternalKeyPaths> {
    std::fs::create_dir_all(dir).with_context(|| format!("mkdir {}", dir.display()))?;
    let dir = dir
        .canonicalize()
        .with_context(|| format!("resolve {}", dir.display()))?;
    let paths = InternalKeyPaths {
        signing: dir.join(SIGNING_KEY_FILE),
        verify: dir.join(VERIFY_KEY_FILE),
    };

    match (paths.signing.is_file(), paths.verify.is_file()) {
        (true, true) => {
            tracing::info!("reusing internal identity keypair in {}", dir.display());
        }
        (false, false) => {
            let (private_pem, public_pem) = cheladb_auth::internal::generate_keypair_pem();
            write_private(&paths.signing, &private_pem)?;
            std::fs::write(&paths.verify, public_pem)
                .with_context(|| format!("write {}", paths.verify.display()))?;
            tracing::info!("wrote internal identity keypair to {}", dir.display());
        }
        _ => anyhow::bail!(
            "only one of {SIGNING_KEY_FILE} / {VERIFY_KEY_FILE} exists in {}; delete both to regenerate",
            dir.display()
        ),
    }
    Ok(paths)
}

fn write_private(path: &Path, pem: &str) -> Result<()> {
    std::fs::write(path, pem).with_context(|| format!("write {}", path.display()))?;
    #[cfg(unix)]
    {
        use std::os::unix::fs::PermissionsExt;
        std::fs::set_permissions(path, std::fs::Permissions::from_mode(0o600))
            .with_context(|| format!("chmod {}", path.display()))?;
    }
    Ok(())
}
```

```rust
    async fn route(&self, req: &RequestParts<'_>, request_id: &str) -> Outcome {
        if req.method == "GET" && req.path == GATEWAY_HEALTH_PATH {
            return respond(200, Vec::new(), json!({ "status": "ok" }));
        }

        let Some(scope) = self.registry.load().scope_for(req.host) else {
            return respond(404, Vec::new(), json!({ "error": "unknown host" }));
        };

        if let Some(preflight) = self.preflight(scope, req) {
            return Outcome::Respond(preflight);
        }

        let endpoint = match match_endpoint(scope, req.method, req.path) {
            Match::Found(endpoint) => endpoint,
            Match::NotFound => {
                return respond(404, Vec::new(), json!({ "error": "no route" }));
            }
            Match::MethodNotAllowed(allowed) => {
                let allow = allowed
                    .iter()
                    .map(|m| m.as_str())
                    .collect::<Vec<_>>()
                    .join(", ");
                return respond(
                    405,
                    vec![("allow", allow)],
                    json!({ "error": "method not allowed" }),
                );
            }
        };

        let cors = self.cors_headers(endpoint, req.headers);

        let identity = match endpoint.policy.auth {
            Auth::Public => None,
            Auth::Platform => {
                match self
                    .authenticate(endpoint.service, req.headers, request_id)
                    .await
                {
                    Ok(token) => Some(token),
                    Err(mut resp) => {
                        resp.headers.extend(cors);
                        return Outcome::Respond(resp);
                    }
                }
            }
        };

        Outcome::Proxy(ProxyPlan {
            endpoint,
            identity,
            response_headers: cors,
        })
    }

    /// Answer a CORS preflight for a Studio endpoint without auth or proxying.
    fn preflight(&self, scope: Scope, req: &RequestParts<'_>) -> Option<GatewayResponse> {
        if req.method != "OPTIONS" {
            return None;
        }
        let origin = header_str(req.headers, "origin")?;
        let requested = header_str(req.headers, "access-control-request-method")?;
        let Match::Found(endpoint) = match_endpoint(scope, requested, req.path) else {
            return None;
        };
        if endpoint.policy.cors != Cors::Studio {
            return None;
        }
        let headers = if self.origin_allowed(origin) {
            vec![
                ("access-control-allow-origin", origin.to_string()),
                ("access-control-allow-methods", requested.to_string()),
                ("access-control-allow-headers", CORS_ALLOW_HEADERS.to_string()),
                ("access-control-max-age", CORS_MAX_AGE_SECS.to_string()),
                ("vary", "Origin".to_string()),
            ]
        } else {
            Vec::new()
        };
        Some(GatewayResponse {
            status: 204,
            headers,
            body: None,
        })
    }

    fn cors_headers(&self, endpoint: &Endpoint, headers: &HeaderMap) -> Vec<(&'static str, String)> {
        if endpoint.policy.cors != Cors::Studio {
            return Vec::new();
        }
        match header_str(headers, "origin") {
            Some(origin) if self.origin_allowed(origin) => vec![
                ("access-control-allow-origin", origin.to_string()),
                ("vary", "Origin".to_string()),
            ],
            _ => Vec::new(),
        }
    }

    fn origin_allowed(&self, origin: &str) -> bool {
        self.studio_origins
            .iter()
            .any(|allowed| allowed == "*" || allowed == origin)
    }

    /// Verify the platform JWT and mint an internal identity for `service`.
    async fn authenticate(
        &self,
        service: Service,
        headers: &HeaderMap,
        request_id: &str,
    ) -> Result<String, GatewayResponse> {
        let token = bearer_token(headers).ok_or_else(|| unauthorized(&AuthError::Unauthorized))?;
        let claims = self.verifier.verify(token).await.map_err(|err| match err {
            AuthError::Unauthorized | AuthError::InvalidToken(_) => unauthorized(&err),
            AuthError::Jwks(_) | AuthError::Config(_) => {
                error!("auth infrastructure error: {err}");
                json_response(503, json!({ "error": "auth unavailable" }))
            }
        })?;
        let identity = Identity {
            sub: claims.sub,
            org_id: claims.org_id,
            auth: AuthMethod::PlatformJwt,
```

```rust
//! Pingora adapter. Only this module and `main.rs` touch Pingora types; the
//! decisions live in `pipeline`.

use crate::pipeline::{GatewayResponse, Outcome, Pipeline, ProxyPlan, RequestParts, REQUEST_ID_HEADER};
use crate::upstreams::Upstreams;
use async_trait::async_trait;
use bytes::Bytes;
use cheladb_auth::internal::IDENTITY_HEADER;
use pingora_core::upstreams::peer::HttpPeer;
use pingora_error::{Error, ErrorSource, ErrorType, Result};
use pingora_http::{RequestHeader, ResponseHeader};
use pingora_proxy::{FailToProxy, ProxyHttp, Session};
use serde_json::json;
use std::net::ToSocketAddrs;
use std::time::{Duration, Instant};
use tracing::info;

const CONNECT_TIMEOUT: Duration = Duration::from_secs(3);
const READ_TIMEOUT: Duration = Duration::from_secs(60);

pub struct Gateway {
    pipeline: Pipeline,
    upstreams: Upstreams,
}

impl Gateway {
    pub fn new(pipeline: Pipeline, upstreams: Upstreams) -> Self {
        Self { pipeline, upstreams }
    }
}

pub struct RequestCtx {
    started: Instant,
    request_id: String,
    host: Option<String>,
    plan: Option<ProxyPlan>,
}

#[async_trait]
impl ProxyHttp for Gateway {
    type CTX = RequestCtx;

    fn new_ctx(&self) -> RequestCtx {
        RequestCtx {
            started: Instant::now(),
            request_id: String::new(),
            host: None,
            plan: None,
        }
    }

    async fn request_filter(&self, session: &mut Session, ctx: &mut RequestCtx) -> Result<bool> {
        // Copy what the pipeline needs so no borrow of `session` is held across `.await`.
        let req = session.req_header();
        let method = req.method.as_str().to_owned();
        let path = req.uri.path().to_owned();
        let headers = req.headers.clone();
        let host = headers
            .get(http::header::HOST)
            .and_then(|v| v.to_str().ok())
            .map(str::to_string)
            .or_else(|| req.uri.authority().map(|a| a.as_str().to_string()));

        let handled = self
            .pipeline
            .handle(&RequestParts {
                method: &method,
                path: &path,
                host: host.as_deref(),
                headers: &headers,
            })
            .await;

        ctx.request_id = handled.request_id;
        ctx.host = host;
        match handled.outcome {
            Outcome::Proxy(plan) => {
                ctx.plan = Some(plan);
                Ok(false)
            }
            Outcome::Respond(resp) => {
                write_gateway_response(session, &resp, &ctx.request_id).await?;
                Ok(true)
            }
        }
    }

    async fn upstream_peer(&self, _session: &mut Session, ctx: &mut RequestCtx) -> Result<Box<HttpPeer>> {
        let plan = ctx
            .plan
            .as_ref()
            .ok_or_else(|| Error::explain(ErrorType::InternalError, "no proxy plan"))?;
        let addr = self.upstreams.addr(plan.endpoint.service);
        // Resolve here: HttpPeer::new panics on resolution failure.
        let socket = addr
            .to_socket_addrs()
            .ok()
            .and_then(|mut addrs| addrs.next())
            .ok_or_else(|| Error::explain(ErrorType::ConnectError, format!("resolve upstream {addr}")))?;
        let mut peer = HttpPeer::new(socket, false, String::new());
        peer.options.connection_timeout = Some(CONNECT_TIMEOUT);
        peer.options.read_timeout = Some(READ_TIMEOUT);
        Ok(Box::new(peer))
    }

    async fn upstream_request_filter(
        &self,
        session: &mut Session,
        upstream: &mut RequestHeader,
        ctx: &mut RequestCtx,
    ) -> Result<()> {
        // Upstreams only ever see the gateway-minted identity.
        upstream.remove_header(IDENTITY_HEADER);
        upstream.remove_header("authorization");
        if let Some(token) = ctx.plan.as_ref().and_then(|p| p.identity.as_deref()) {
            upstream.insert_header(IDENTITY_HEADER, token)?;
        }
        upstream.insert_header(REQUEST_ID_HEADER, ctx.request_id.as_str())?;

        if let Some(ip) = session
            .client_addr()
            .and_then(|a| a.as_inet())
            .map(|a| a.ip().to_string())
        {
            let forwarded_for = match upstream
                .headers
                .get("x-forwarded-for")
                .and_then(|v| v.to_str().ok())
            {
                Some(previous) => format!("{previous}, {ip}"),
                None => ip,
            };
            upstream.insert_header("x-forwarded-for", forwarded_for)?;
        }
        upstream.insert_header("x-forwarded-proto", "http")?;
        if let Some(host) = &ctx.host {
            upstream.insert_header("x-forwarded-host", host.as_str())?;
        }
        Ok(())
    }

    async fn response_filter(
        &self,
        _session: &mut Session,
        response: &mut ResponseHeader,
        ctx: &mut RequestCtx,
    ) -> Result<()> {
        response.insert_header(REQUEST_ID_HEADER, ctx.request_id.as_str())?;
        if let Some(plan) = &ctx.plan {
            for (name, value) in &plan.response_headers {
                response.insert_header(*name, value.as_str())?;
            }
        }
        Ok(())
    }

    async fn fail_to_proxy(&self, session: &mut Session, e: &Error, ctx: &mut RequestCtx) -> FailToProxy {
        let status: u16 = match (e.esource(), e.etype()) {
            // The client went away; nothing to write.
            (
                ErrorSource::Downstream,
                ErrorType::ReadError | ErrorType::WriteError | ErrorType::ConnectionClosed,
            ) => 0,
            (ErrorSource::Downstream, _) => 400,
            (_, ErrorType::HTTPStatus(code)) => *code,
            (_, ErrorType::ConnectTimedout | ErrorType::ReadTimedout | ErrorType::WriteTimedout) => 504,
            (
                _,
                ErrorType::ConnectRefused | ErrorType::ConnectNoRoute | ErrorType::ConnectError,
            ) => 502,
            (ErrorSource::Upstream, _) => 502,
            _ => 500,
        };
        if status > 0 {
            let message = match status {
                502 => "upstream unavailable",
                504 => "upstream timed out",
                400 => "bad request",
                _ => "internal error",
            };
            let headers = ctx
                .plan
                .as_ref()
                .map(|p| p.response_headers.clone())
                .unwrap_or_default();
            let resp = GatewayResponse {
                status,
                headers,
                body: Some(json!({ "error": message })),
            };
            let _ = write_gateway_response(session, &resp, &ctx.request_id).await;
        }
        FailToProxy {
            error_code: status,
            can_reuse_downstream: false,
        }
    }

    async fn logging(&self, session: &mut Session, _e: Option<&Error>, ctx: &mut RequestCtx) {
        let req = session.req_header();
        let status = session.response_written().map_or(0, |r| r.status.as_u16());
        let (route, service) = ctx
            .plan
            .as_ref()
            .map_or(("-", "-"), |p| (p.endpoint.name, p.endpoint.service.name()));
        info!(
            request_id = %ctx.request_id,
            method = %req.method,
            host = ctx.host.as_deref().unwrap_or("-"),
            path = req.uri.path(),
            route,
            service,
            status,
            duration_ms = ctx.started.elapsed().as_millis() as u64,
            "request"
        );
    }
}

async fn write_gateway_response(session: &mut Session, resp: &GatewayResponse, request_id: &str) -> Result<()> {
    let body = resp.body.as_ref().map(|b| Bytes::from(b.to_string()));
    let mut header = ResponseHeader::build(resp.status, None)?;
    header.insert_header(REQUEST_ID_HEADER, request_id)?;
    for (name, value) in &resp.headers {
        header.insert_header(*name, value.as_str())?;
    }
    match &body {
        Some(b) => {
            header.insert_header("content-type", "application/json")?;
            header.set_content_length(b.len())?;
        }
        None => header.set_content_length(0)?,
    }
    session
        .write_response_header(Box::new(header), body.is_none())
        .await?;
    if let Some(b) = body {
        session.write_response_body(Some(b), true).await?;
    }
    Ok(())
}
```

```rust
    let registry = Arc::new(SharedRegistry::new(Registry::new(&config.platform_hosts)));
    let pipeline = Pipeline::new(registry, config.studio_origins.clone(), verifier, signer);

    let mut conf = ServerConf::default();
    // Pingora's defaults assume zero-downtime binary upgrades with long grace
    // periods. Under `just dev`, Compose, or k8s a process manager restarts us,
    // so exit promptly on SIGTERM.
    conf.grace_period_seconds = Some(0);
    conf.graceful_shutdown_timeout_seconds = Some(5);
    conf.threads = std::thread::available_parallelism().map_or(1, |n| n.get());

    let mut server = Server::new_with_opt_and_conf(None, conf);
    server.bootstrap();
    let mut service = pingora_proxy::http_proxy_service(
        &server.configuration,
        Gateway::new(pipeline, config.upstreams.clone()),
    );
    service.add_tcp(&config.listen);
    server.add_service(service);

    info!(listen = %config.listen, "gateway listening");
    server.run_forever();
}
```
