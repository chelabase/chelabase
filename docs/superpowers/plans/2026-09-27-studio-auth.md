# Studio Auth + Landing Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Studio users sign up or sign in on Zitadel's hosted login and land on `/app`. That page shows their tenant and project, lists the project's databases, and creates new ones, all through the gateway.

**Architecture:**
- **API:** a new `GET /v1/me`, declared in `cheladb-routes` and served by the orchestrator. It returns the caller, their tenant, projects and databases, or `tenant: null` when the caller's org is unbound.
- **Bootstrap:** registers a PKCE SPA app in Zitadel, points Zitadel's SMTP at a Mailpit container so signup verification emails can be read, and writes Studio's `.env.local`.
- **Studio:** uses `oidc-client-ts` + `react-oidc-context` for the redirect flow, and a small typed API client for the gateway.

**Tech Stack:** Rust (axum, sqlx, reqwest), React 19, TanStack Router, oidc-client-ts 3.5, react-oidc-context 3.3, Vitest + Testing Library + jsdom, Mailpit, just.

**Spec:** `docs/superpowers/specs/2026-09-27-studio-auth-design.md`

- `GET /v1/me` never returns `admin_password` or `container_id`.

- The demo-org pin is exactly one scope (`urn:zitadel:iam:org:id:{VITE_ZITADEL_ORG_ID}`).

## Review Focus

1. **`/callback` opened without `code`/`state`** (bookmarked or refreshed) must go to `/` instead of spinning on "Signing you in…" forever. (Task 5: `callbackOutcome` test)
2. **An org that is bound but whose tenant row is gone** must return `tenant: null` with `200`, not `500`. (Task 2)
3. **Database names with surrounding whitespace, or blank,** are trimmed or blocked in the form, and a server `400`/`409` shows up as a visible error. (Task 5)
4. **Re-running bootstrap** must not duplicate the Studio app or the SMTP provider. An existing inactive Mailpit config is activated rather than duplicated. (Task 3: `find_smtp_config` tests plus the live re-run)
5. **A `401` from the gateway** (expired or refused token) restarts sign-in exactly once via `onUnauthorized`, rather than failing silently. (Task 4)

    /// The tenant, its projects (by slug) and their databases (oldest first).
    pub async fn tenant_overview(
        &self,
        tenant_id: TenantId,
    ) -> Result<Option<TenantOverview>, MetadataError> {
        let Some(tenant) = sqlx::query("SELECT slug FROM tenants WHERE id = $1")
            .bind(tenant_id.as_uuid())
            .fetch_optional(&self.pool)
            .await?
        else {
            return Ok(None);
        };
        let projects = sqlx::query("SELECT id, slug FROM projects WHERE tenant_id = $1 ORDER BY slug")
            .bind(tenant_id.as_uuid())
            .fetch_all(&self.pool)
            .await?
            .iter()
            .map(|r| (ProjectId(r.get("id")), r.get::<String, _>("slug")))
            .collect();
        let databases = sqlx::query(
            r#"
            SELECT d.id, d.project_id, p.tenant_id, d.name, d.status, d.container_id,
                   d.host, d.port, d.admin_password, d.error
            FROM databases d
            JOIN projects p ON p.id = d.project_id
            WHERE p.tenant_id = $1
            ORDER BY d.created_at
            "#,
        )
        .bind(tenant_id.as_uuid())
        .fetch_all(&self.pool)
        .await?
        .iter()
        .map(database_from_row)
        .collect();
        Ok(Some(group_overview(tenant_id, tenant.get("slug"), projects, databases)))
    }

export interface StudioEnv {
  issuer: string;
  clientId: string;
  projectId: string;
  orgId: string;
  apiUrl: string;
}

const KEYS: Record<keyof StudioEnv, string> = {
  issuer: "VITE_ZITADEL_ISSUER",
  clientId: "VITE_ZITADEL_CLIENT_ID",
  projectId: "VITE_ZITADEL_PROJECT_ID",
  orgId: "VITE_ZITADEL_ORG_ID",
  apiUrl: "VITE_API_URL",
};

export function readEnv(source: Record<string, string | undefined>): StudioEnv {
  const value = (key: keyof StudioEnv) => source[KEYS[key]]?.trim() ?? "";
  const missing = (Object.keys(KEYS) as (keyof StudioEnv)[])
    .filter((key) => value(key) === "")
    .map((key) => KEYS[key]);
  if (missing.length > 0) {
    throw new Error(
      `Studio is missing ${missing.join(", ")}. Run \`just zitadel-bootstrap\` to write apps/studio/.env.local, then restart Studio.`,
    );
  }
  return {
    issuer: value("issuer"),
    clientId: value("clientId"),
    projectId: value("projectId"),
    orgId: value("orgId"),
    apiUrl: value("apiUrl"),
  };
}

import type {
  CreateDatabaseAccepted,
  CreateDatabaseRequest,
  DatabaseDetail,
  MeResponse,
} from "@cheladb/types";

export class ApiError extends Error {
  readonly status: number;
  constructor(status: number, message: string) {
    super(message);
    this.name = "ApiError";
    this.status = status;
  }
}

export interface ApiClientOptions {
  baseUrl: string;
  getToken: () => string | undefined;
  /** Called on 401: the token was refused, so sign-in must restart. */
  onUnauthorized: () => void;
  fetchImpl?: typeof fetch;
}

export interface ApiClient {
  me(): Promise<MeResponse>;
  createDatabase(request: CreateDatabaseRequest): Promise<CreateDatabaseAccepted>;
  getDatabase(id: string): Promise<DatabaseDetail>;
}

export function createApiClient(options: ApiClientOptions): ApiClient {
  const fetchImpl = options.fetchImpl ?? globalThis.fetch.bind(globalThis);

  async function request<T>(method: string, path: string, body?: unknown): Promise<T> {
    const headers: Record<string, string> = { Accept: "application/json" };
    const token = options.getToken();
    if (token) headers.Authorization = `Bearer ${token}`;
    if (body !== undefined) headers["Content-Type"] = "application/json";

    const response = await fetchImpl(`${options.baseUrl}${path}`, {
      method,
      headers,
      body: body === undefined ? undefined : JSON.stringify(body),
    });
    if (response.status === 401) {
      options.onUnauthorized();
      throw new ApiError(401, await errorMessage(response));
    }
    if (!response.ok) throw new ApiError(response.status, await errorMessage(response));
    return (await response.json()) as T;
  }

  return {
    me: () => request<MeResponse>("GET", "/v1/me"),
    createDatabase: (req) => request<CreateDatabaseAccepted>("POST", "/v1/databases", req),
    getDatabase: (id) => request<DatabaseDetail>("GET", `/v1/databases/${encodeURIComponent(id)}`),
  };
}

async function errorMessage(response: Response): Promise<string> {
  const text = await response.text().catch(() => "");
  try {
    const parsed = JSON.parse(text) as { error?: unknown };
    if (typeof parsed.error === "string") return parsed.error;
  } catch {
    // not JSON; fall through
  }
  return text || `Request failed with status ${response.status}`;
}

export function callbackOutcome(state: {
  isLoading: boolean;
  isAuthenticated: boolean;
  error: Error | undefined;
  hasAuthParams: boolean;

import { useState, type FormEvent } from "react";
import type { DatabaseStatus, ProjectId, TenantId } from "@cheladb/types";
import { Button } from "@/components/ui/button";
import type { ApiClient } from "@/lib/api";

type FormState =
  | { status: "idle" }
  | { status: "working"; name: string; phase: DatabaseStatus }
  | { status: "done"; name: string }
  | { status: "error"; message: string };

export interface CreateDatabaseFormProps {
  api: ApiClient;
  tenantId: TenantId;
  projectId: ProjectId;
  /** Called whenever the database list should be refreshed. */
  onSettled: () => void;
  pollIntervalMs?: number;
  maxPolls?: number;
}

const sleep = (ms: number) => new Promise((resolve) => setTimeout(resolve, ms));

export function CreateDatabaseForm({ api, tenantId, projectId, onSettled, pollIntervalMs = 2000, maxPolls = 90 }: CreateDatabaseFormProps) {
  const [name, setName] = useState("");
  const [state, setState] = useState<FormState>({ status: "idle" });
  const trimmed = name.trim();
  const busy = state.status === "working";

  async function submit(event: FormEvent) {
    event.preventDefault();
    if (!trimmed || busy) return;
    setState({ status: "working", name: trimmed, phase: "pending" });
    try {
      const accepted = await api.createDatabase({ tenant_id: tenantId, project_id: projectId, name: trimmed });
      onSettled();
      for (let i = 0; i < maxPolls; i++) {
        await sleep(pollIntervalMs);
        const db = await api.getDatabase(accepted.database_id);
        if (db.status === "ready") {
          setState({ status: "done", name: trimmed });
          setName("");
          onSettled();
          return;
        }
        if (db.status === "failed") {
          setState({ status: "error", message: db.error ?? "Provisioning failed." });
          onSettled();
          return;
        }
        setState({ status: "working", name: trimmed, phase: db.status });
      }
      setState({ status: "error", message: `${trimmed} is still provisioning; check the list again shortly.` });
      onSettled();
    } catch (err) {
      setState({ status: "error", message: err instanceof Error ? err.message : String(err) });
    }
  }

  return (
    <form onSubmit={submit} className="flex flex-wrap items-end gap-3">
      <label className="flex flex-col gap-1 text-sm">
        <span>Database name</span>
        <input
          value={name}
          onChange={(e) => setName(e.target.value)}
          disabled={busy}
          className="h-8 w-64 rounded-lg border border-input bg-background px-2"
          placeholder="web1"
        />
      </label>
      <Button type="submit" disabled={!trimmed || busy}>Create database</Button>
      {state.status === "working" && <p className="text-sm text-muted-foreground">Creating {state.name}… ({state.phase})</p>}
      {state.status === "done" && <p className="text-sm">{state.name} is ready</p>}
      {state.status === "error" && <p role="alert" className="text-sm text-destructive">{state.message}</p>}
    </form>
  );
}

function AppPage() {
  const auth = useAuth();
  const env = useStudioEnv();
  // Refs keep the API client stable while tokens refresh underneath it.
  const authRef = useRef(auth);
  authRef.current = auth;

  const api = useMemo(
    () =>
      createApiClient({
        baseUrl: env.apiUrl,
        getToken: () => authRef.current.user?.access_token,
        onUnauthorized: () => void authRef.current.signinRedirect(),
      }),
    [env.apiUrl],
  );

  const needsSignIn = !auth.isLoading && !auth.isAuthenticated && !auth.activeNavigator && !auth.error;

    if (needsSignIn) void auth.signinRedirect();

  }
  return (
